# 📊 Analytical & Energy-Related Experience Showcase

This document highlights how the **EV Charging Load Prediction** project demonstrates relevant analytical and energy-related competencies.

---

## 🎯 Project Overview

**Domain**: Energy Analytics | Electric Vehicle Infrastructure  
**Type**: Predictive Modeling & Data Analysis  
**Industry Application**: Utility Planning & EV Infrastructure Management

### Business Context
Predicting residential EV charging energy consumption (kWh) from real-world Norwegian apartment data to support:
- **Infrastructure Planning**: Sizing electrical transformers for EV charging installations
- **Load Management**: Scheduling and balancing electrical loads
- **Revenue Forecasting**: Estimating energy costs before installing charging stations

---

## 💼 Analytical Experience Demonstrated

### 1. **Data Analysis & Processing**
- **Dataset Management**: Worked with 6,833 real-world charging sessions from Mendeley open dataset
- **Data Integration**: Merged multiple data sources (EV charging reports + local traffic distribution)
- **Data Cleaning**: 
  - Handled string-to-numeric conversions
  - Processed date/time features
  - Removed irrelevant columns
  - Managed data type consistency

### 2. **Feature Engineering**
- **Feature Selection**: Identified and utilized 26 relevant features for prediction
- **Domain Knowledge Application**: Combined charging behavior data with external traffic patterns
- **Temporal Analysis**: Incorporated time-based features (plugin hours, duration)

### 3. **Statistical Modeling**
- **Baseline Modeling**: Established Linear Regression baseline (MSE: 131.4 kWh²)
- **Advanced Modeling**: Implemented neural network achieving 12% improvement (MSE: 115.2 kWh²)
- **Performance Metrics**: Used appropriate error metrics (MSE) for regression tasks
- **Model Comparison**: Quantified improvement over baseline methods

### 4. **Machine Learning Implementation**
- **Framework**: PyTorch for deep learning implementation
- **Architecture Design**: 3-layer fully-connected neural network (26→56→26→1)
- **Hyperparameter Optimization**: 
  - Learning rate: 0.0007
  - Training epochs: 3000-4500
  - Network architecture tuning
- **Model Validation**: Proper train/test split (80/20) with controlled random seed
